Tab bar con highlight deslizante

El subrayado se ancla al tab activo con anchor(): al cambiar de tab, anchor-name: --active se mueve y el indicador se desliza solo con una transición de inset. Sin JavaScript midiendo posiciones.

Overview. CSS Anchor Positioning permite atar un elemento a otro declarativamente con anchor-name y position-anchor. Aquí el tab activo declara anchor-name: --active y el pseudo-elemento del contenedor se ancla a él con anchor(left) y anchor(right). El sliding highlight es una transición de inset: cuando el anchor-name cambia de tab, el navegador interpola las posiciones — sin una línea de JS midiendo rects.
El ancla. Solo puede haber un elemento con anchor-name: --active, así que el nombre viaja con la selección. El indicador usa position-anchor: --active y se ubica con inset-inline-start: anchor(left) / inset-inline-end: anchor(right): su ancho siempre es el del tab anclado, esté donde esté. La guía manda no usar position-area — no se puede transicionar.
Animación. La transición de inset vive dentro de @media (prefers-reduced-motion: no-preference): quien pide menos movimiento en el SO ve el cambio instantáneo. Y quien navega con teclado (flechas, que seleccionan al enfocar) ve el mismo deslizamiento suave que quien hace click.
Accesibilidad. El highlight es decorativo: el estado real vive en aria-selected, y el CSS se aplica desde ese atributo — visual y accesible nunca discrepan. El indicador se dibuja con border porque forced-colors elimina background y box-shadow. Flechas ←/→ mueven y seleccionan; Home/End saltan a los extremos; el foco que entra al grupo aterriza en el tab seleccionado.
Fallback. Donde no hay Anchor Positioning, un @supports not (position-anchor: auto) dibuja el subrayado estático en el tab seleccionado (vía ::after, sin cambiar sus dimensiones) y oculta el indicador deslizante. La interfaz queda 100% funcional — solo pierde el deslizamiento.
